# WPF Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Microsoft Store build's Electron runtime with a feature-equivalent .NET Framework 4.8 WPF desktop pet whose MSIX is at most 5 MB.

**Architecture:** A dependency-free WPF executable owns the transparent pet window, timers, tray icon, settings, and single-instance lifetime. A UI-independent state machine preserves the existing behavior and is compiled into a tiny console test executable before it is used by the WPF window.

**Tech Stack:** C# 7.3, WPF, .NET Framework 4.8, Windows Forms `NotifyIcon`, MSBuild, WinApp CLI, PowerShell

**Spec:** `docs/superpowers/specs/2026-09-04-wpf-port-design.md`

## Global Constraints

- Support Windows 10/11 x64 and Microsoft Store only.
- Add no NuGet packages and do not bundle .NET, Chromium, Node.js, or Electron.
- Keep the existing Electron source in the repository but exclude it from the native MSIX.
- Preserve the existing Store identity and publisher.
- Keep original PNG assets unless the completed MSIX exceeds 5 MB.

```csharp
internal static class StateMachineTests
{
    private static void Require(bool value, string name) { if (!value) throw new Exception(name); }
    public static int Main()
    {
        var now = new DateTime(2026, 9, 4, 0, 0, 0, DateTimeKind.Utc);
        var bunny = new BunnyStateMachine(now);
        Require(bunny.State == BunnyState.Idle && bunny.Direction == -1, "initial state");
        Require(bunny.ChooseNext(0.50, now) == BunnyState.Walk, "walk range");
        bunny.SetPaused(true);
        Require(bunny.State == BunnyState.Sleep, "pause sleeps");
        bunny.SetPaused(false);
        bunny.Touch(now);
        Require(bunny.ChooseNext(0.10, now.AddSeconds(121)) == BunnyState.Sleep, "inactivity sleeps");
        Require(bunny.TurnAround() == 1, "turn around");
        Console.WriteLine("Native state tests passed.");
        return 0;
    }
}
```
