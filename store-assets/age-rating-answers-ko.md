# 연령 등급 설문 응답안

이 응답안은 현재 버전 1.0.1의 실제 기능을 기준으로 작성되었습니다.

| 항목 | 응답 |
|---|---|
| 폭력 또는 유혈 표현 | 없음 |
| 공포 또는 위협적 콘텐츠 | 없음 |
| 성적 콘텐츠 또는 노출 | 없음 |
| 욕설 또는 거친 언어 | 없음 |
| 술, 담배 또는 약물 | 없음 |
| 도박 또는 모의 도박 | 없음 |
| 사용자 생성 콘텐츠 | 없음 |
| 사용자 간 온라인 상호작용 | 없음 |
| 위치 정보 공유 | 없음 |
| 개인정보 수집 또는 공유 | 없음 |
| 디지털 구매 또는 현금성 거래 | 없음 |
| 외부 웹 콘텐츠 접근 | 없음 |
| 광고 | 없음 |

예상 등급은 전체 이용가에 해당하지만, 최종 등급은 Partner Center의 국제연령등급연합(IARC) 설문 결과로 확정됩니다.
