# 인증 참고 사항

이 제품은 Windows 바탕화면 위에서 동작하는 인터랙티브 롭이어 토끼 데스크톱 펫 "민트 키우기"입니다. 계정, 로그인, 결제, 네트워크 연결 또는 외부 서비스가 필요하지 않습니다.

`runFullTrust` 제한 기능은 .NET Framework 4.8 기반 WPF 고전적 Windows 데스크톱 프로세스를 실행하고, 프레임 없는 투명 창을 항상 위에 표시하며, 화면 안에서 창 위치를 이동하기 위해 필요합니다. 앱은 관리자 권한을 요청하지 않으며 다른 프로세스에 코드를 삽입하거나 시스템 보안 설정을 변경하지 않습니다.

| 시험 항목 | 시험 방법 | 예상 결과 |
|---|---|---|
| 기본 실행 | 시작 메뉴에서 앱을 실행합니다. | 화면 오른쪽 아래에 토끼가 나타나고 자동 행동을 시작합니다. |
| 쓰다듬기 | 토끼를 클릭하거나 마우스로 쓰다듬습니다. | 순수 이모티콘 말풍선과 하트 반응이 나타나며 호감도가 오릅니다. |
| 위치 이동 | 토끼를 마우스로 드래그합니다. | 화면 안의 원하는 위치로 이동합니다. |
| 제어 메뉴 | 토끼를 우클릭합니다. | "민트 대시보드 및 설정", "놀자!/나대지마", "민트 자리로 부르기", "민트 재우기(종료)" 메뉴가 나타납니다. |
| 대시보드 | 우클릭 메뉴에서 "민트 대시보드 및 설정"을 선택합니다. | 호감도, 항상 위 표시 등을 관리하는 전용 창이 열립니다. |
| 완전 종료 | 우클릭 메뉴 또는 트레이 아이콘에서 "민트 재우기(종료)"를 선택합니다. | 앱과 알림 영역 아이콘이 모두 종료됩니다. |

앱에는 광고, 원격 코드, 분석 SDK, 텔레메트리 또는 자동 업데이트 모듈이 없습니다. 실물 반려동물 참고 사진을 기반으로 제작된 정지 이미지·프레임 애니메이션만 리소스로 패키지에 포함되며, 원본 파일이나 개인 식별 정보는 포함되지 않습니다. 별도의 시험 계정은 필요하지 않습니다.
