# 인증 참고 사항

이 제품은 Windows 바탕화면 위에서 동작하는 작은 롭이어 토끼 데스크톱 펫입니다. 계정, 로그인, 결제, 네트워크 연결 또는 외부 서비스가 필요하지 않습니다.

`runFullTrust` 제한 기능은 Electron 기반의 고전적 Windows 데스크톱 프로세스를 실행하고, 프레임 없는 투명 창을 항상 위에 표시하며, 화면 안에서 창 위치를 이동하기 위해 필요합니다. 앱은 관리자 권한을 요청하지 않으며 다른 프로세스에 코드를 삽입하거나 시스템 보안 설정을 변경하지 않습니다.

| 시험 항목 | 시험 방법 | 예상 결과 |
|---|---|---|
| 기본 실행 | 시작 메뉴에서 앱을 실행합니다. | 화면에 작은 토끼가 나타나고 자동 행동을 시작합니다. |
| 쓰다듬기 | 토끼를 한 번 클릭합니다. | 말풍선과 하트 반응이 나타납니다. |
| 일어서기 | 토끼를 더블클릭합니다. | 토끼가 잠시 일어선 자세를 보입니다. |
| 위치 이동 | 토끼를 마우스로 드래그합니다. | 화면 안의 원하는 위치로 이동합니다. |
| 제어 메뉴 | 토끼를 우클릭합니다. | 일시 정지, 항상 위 표시, 위치 초기화와 종료 메뉴가 나타납니다. |
| 완전 종료 | 우클릭 메뉴에서 '토끼 보내기'를 선택합니다. | 앱과 알림 영역 아이콘이 모두 종료됩니다. |

앱에는 광고, 원격 코드, 분석 SDK, 텔레메트리 또는 자동 업데이트 모듈이 없습니다. 원본 참고 사진은 패키지에 포함되지 않습니다. 별도의 시험 계정은 필요하지 않습니다.
