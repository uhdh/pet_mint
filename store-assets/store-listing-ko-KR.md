## 설명

**내 토끼 데스크톱 펫**은 작고 사랑스러운 롭이어 토끼를 Windows 바탕화면에 데려오는 가벼운 데스크톱 앱입니다.

토끼는 화면 아래를 천천히 산책하고, 가장자리에 닿으면 스스로 방향을 바꿉니다. 가끔 일어서서 주변을 살피거나 편안하게 잠이 들기도 합니다. 토끼를 클릭하면 말풍선과 하트로 반응하며, 더블클릭하면 호기심 있게 일어섭니다. 마우스로 끌어서 원하는 위치에 놓을 수도 있습니다.

우클릭 메뉴에서는 움직임을 잠시 멈추거나 다시 시작할 수 있습니다. 항상 위에 표시 옵션과 화면 오른쪽 아래로 돌아가기 기능도 제공합니다. 앱은 계정이나 인터넷 연결 없이 동작하며 광고, 분석 도구 또는 데이터 수집 기능을 포함하지 않습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 자동 산책 | 화면을 천천히 돌아다니고 가장자리에서 방향을 바꿉니다. |
| 쓰다듬기 반응 | 클릭하면 말풍선과 하트로 반응합니다. |
| 다양한 행동 | 일어서기, 잠자기, 호기심 표현을 자연스럽게 반복합니다. |
| 자유로운 배치 | 드래그해서 바탕화면의 원하는 위치로 옮길 수 있습니다. |
| 간단한 제어 | 우클릭 메뉴에서 일시 정지, 항상 위 표시, 위치 초기화, 종료가 가능합니다. |
| 오프라인 동작 | 로그인, 네트워크 연결, 광고 또는 데이터 수집이 없습니다. |

## 새로운 기능

버전 1.0.1은 Microsoft Store 첫 출시 버전입니다. 작은 1/3 크기의 토끼, 자동 산책, 쓰다듬기 반응, 드래그 이동, 잠자기 동작과 우클릭 제어 메뉴를 포함합니다.
