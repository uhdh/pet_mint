민트 키우기 데스크톱 펫 사용법
============================

1. "BunnyPet.exe" 또는 바탕화면의 "민트 키우기"를 실행합니다.
2. 기본 상태는 얌전히 멈춰있는 "식빵 굽기" 자세입니다.
   - 멈춰 있을 때는 간헐적으로 식빵(🍞), zzz(💤), 😴 등 귀여운 이모티콘을 보여줍니다.
   - 가끔 기분이 좋아지면 몸을 잘게 떨며 "갸르릉" 골골송을 부릅니다.
3. 민트를 움직이게 하려면:
   - 우클릭 메뉴에서 [🎉 놀자! (움직이기)]를 누르거나, 민트를 더블클릭합니다.
4. 놀고 있는 민트를 다시 얌전하게 멈추게 하려면:
   - 우클릭 메뉴에서 [🛑 나대지마 (멈추기)]를 누르거나, 민트를 더블클릭합니다.
5. 민트를 클릭하거나 살살 문지르면 기분 좋게 쓰다듬어집니다 (멈춤 상태에서는 갸르릉 반응).
6. 마우스로 끌어 화면 어디든 원하는 곳에 데려다 놓을 수 있습니다.
7. 민트를 우클릭하면 다음 기능들을 이용할 수 있습니다:
   - 🎉 놀자! / 🛑 나대지마 (움직이기 / 멈추기 전환)
   - 🖐️ 민트 쓰다듬기
   - 🎁 민트에게 선물하기 (건초, 의자, 인형, 가방, 집)
   - 📌 항상 위에 표시
   - ↩ 민트 자리로 부르기 (화면 오른쪽 아래)
   - 👋 민트 재우기 (종료)
8. Esc 키를 누르면 민트가 즉시 멈추고 화면 오른쪽 아래 기본 자리로 돌아옵니다.
9. 👑 전체 해금 치트키:
   - 전역 단축키: [Ctrl + Alt + U] (또는 Ctrl + Shift + U)
   - 또는 민트 우클릭 메뉴 -> [👑 [치트키] 전체 즉시 해금 (호감도 100점 MAX)]
   - 또는 트레이 아이콘 우클릭 -> [👑 [치트키] 전체 즉시 해금]
   - 또는 대시보드(설정) -> 시스템 설정 -> [✨ 전체 해금하기]
   - 즉시 호감도가 100점(MAX)으로 채워지며 모든 특별 포즈 7종과 선물 아이템 5종이 전부 해금됩니다.

Windows SmartScreen 안내
------------------------
개인용으로 만든 코드 서명 없는 앱이라 최초 실행 때 경고가 뜰 수 있습니다.
경고 창에서 "추가 정보"를 누른 뒤 "실행"을 선택하세요.

개인정보
--------
앱에는 원본 사진이 포함되지 않습니다. 인터넷 연결, 광고, 분석 또는 데이터 수집 기능도 없습니다.
