내 토끼 데스크톱 펫 사용법
============================

1. 이 압축 파일을 원하는 폴더에 모두 풉니다.
2. "My Bunny Desktop Pet.exe"를 더블클릭합니다.
3. 토끼를 클릭하면 쓰다듬기 반응을 합니다.
4. 토끼를 더블클릭하면 일어서서 주변을 살핍니다.
5. 마우스로 끌어 원하는 곳에 놓을 수 있습니다.
6. 토끼를 우클릭하면 다음 메뉴가 나옵니다.
   - 잠깐 멈추기 / 다시 움직이기
   - 항상 위에 표시
   - Windows 시작 시 함께 실행
   - 오른쪽 아래로 돌아가기
   - 토끼 보내기(완전 종료)
7. Esc 키를 누르면 토끼가 화면 오른쪽 아래로 돌아갑니다.

Windows SmartScreen 안내
------------------------
개인용으로 만든 코드 서명 없는 앱이라 최초 실행 때 경고가 뜰 수 있습니다.
경고 창에서 "추가 정보"를 누른 뒤 "실행"을 선택하세요.

개인정보
--------
앱에는 원본 사진이 포함되지 않습니다. 인터넷 연결, 광고, 분석 또는 데이터 수집 기능도 없습니다.
